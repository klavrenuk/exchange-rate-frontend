# Exchange Rate Frontend

Фронтенд для управления бэкендом exchange-rate-backend. Подключается к API по адресу из `.env`.

## Установка
```bash
npm install
```

## Настройка
Скопируйте `.env.example` в `.env` и при необходимости измените `VITE_API_BASE_URL` (по умолчанию http://127.0.0.1:8000).

## Запуск в dev-режиме
```bash
npm run dev
```
Откроется на http://localhost:5173

## Сборка
```bash
npm run build
npm run preview
```

## Возможности
- Статус сервиса (кол-во валют, курсов, графиков, отправленных)
- Ручной запуск задач НБРБ: синхронизация справочника, загрузка истории, обновление на сегодня, формирование Excel-отчёта и отправка
- Ручной запуск задач IEA: поиск графиков на первой странице, скачивание новых, отправка непросланных по одному
- Запуск всех задач одним кликом
- Просмотр истории запусков задач с деталями
